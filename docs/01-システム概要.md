# システム概要

## プロジェクト名
出退勤システム（Attendance Management System）

## 目的

Dockerを使えない環境でも、ローカル実行とPaaSデプロイを容易にする出退勤管理システムです。

## 技術スタック

### バックエンド
- Flask 3.x
- Flask-Login
- Flask-SQLAlchemy / SQLAlchemy 2.x
- 認証: ユーザーID+パスワード

### データベース
- 開発: SQLite
- 本番: PostgreSQL 推奨

### フロントエンド
- Jinja2テンプレート
- Bootstrap 5
- バニラJavaScript

## アーキテクチャ

リファクタ後は `App Factory + Blueprint` 構成です。

- `attendance_app/__init__.py`: `create_app()`
- `attendance_app/routes/*`: ルーティング
- `attendance_app/services/*`: 業務ロジック
- `attendance_app/utils/*`: 共通ユーティリティ
- `attendance_app/models/*`: ORMモデル

## 主な機能

1. ログイン/ログアウト
2. 出勤・退勤・休憩の打刻
3. 管理者によるシフト管理（作成/編集/削除）
4. ユーザー管理
5. 監査ログ閲覧とCSVエクスポート
6. 出退勤データCSVエクスポート

## セキュリティ

- CSRF保護
- パスワードハッシュ化
- 監査ログ署名（HMAC-SHA256）
- セッションCookie保護

## 運用

- 起動: `flask --app app run`
- 初期DB作成: `flask --app app init-db`
- 本番: `gunicorn app:app`
- マイグレーション基盤: Alembic骨組み追加済み（`migrations/`）
